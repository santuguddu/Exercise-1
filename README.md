# Medical & Travel Expense Request

## 📌 Project Overview

This project recreates the **Medical & Travel Expense Request** document using:

- HTML
- CSS
- JavaScript

The webpage is designed to look similar to the provided WCB document/PDF.

## ✨ Features

- WCB document-style header
- Employee and claim information
- Medical expense tables
- Prescription Drugs section
- Over-the-Counter Drugs section
- Medical Supplies section
- Footer and page layout
- Print-friendly design
- Dynamic table data using JavaScript

## 🔄 Dynamic Data

The table rows are generated dynamically using JavaScript arrays.
